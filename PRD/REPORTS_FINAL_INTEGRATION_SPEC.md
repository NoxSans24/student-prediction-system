# REPORTS_FINAL_INTEGRATION_SPEC.md

## 1. Tujuan

Tahap ini menjadi penghubung terakhir seluruh modul utama aplikasi **Student Performance Analytics**.

Fokusnya:

* Reports
* Export PDF
* Export Excel
* Export CSV
* Integrasi seluruh service
* Final integration
* Error handling
* Security
* Performance
* Testing
* Deployment readiness

Alur akhirnya:

```text
Dataset
   ↓
Validation
   ↓
Cleaning
   ↓
Academic Records
   ↓
Analytics ─────┐
Risk Engine ───┤
ML Engine ─────┤
                ▼
            Dashboard
                │
                ▼
             Reports
                │
       ┌────────┼────────┐
       ▼        ▼        ▼
      PDF     Excel      CSV
```

---

# 2. Scope Reports

Sistem memiliki 4 jenis report:

```text
1. Overall Performance Report
2. Student Report
3. Risk Report
4. ML Report
```

Semua report menggunakan data aktual.

Tidak boleh ada data dummy atau angka hardcoded.

# 4. Report Architecture

```text
Frontend
   ↓
Reports Route / API
   ↓
Report Service
   ├── Student Service
   ├── Analytics Service
   ├── Risk Service
   └── ML Service
   ↓

   ↓
```
